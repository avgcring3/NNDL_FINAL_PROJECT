# Data

## Source

The MVP corpus is stored in `data/raw/datasets.json`. It is a local educational corpus assembled from the RideFlow NN project README and implementation notes in this repository.

## What Is Indexed

The index contains short documents about:

- project overview;
- demand forecasting;
- trip price estimation;
- geocoding;
- routing;
- weather signals;
- traffic assumptions;
- Streamlit dashboard workflow;
- generated artifacts;
- limitations;
- RAG index design;
- RAG answer policy.

## Scale

The MVP contains 12 text records. This satisfies the minimum homework requirement of 10 records. It is intentionally smaller than the recommended 1000-record target so the project remains self-contained and reproducible without a dataset download.

## Generated Files

- `data/processed/documents.jsonl`
- `data/processed/chunks.jsonl`
- `data/index/vectorizer.pkl`
- `data/index/matrix.npz`
- `data/index/chunks.jsonl`

These files are generated by `python scripts/build_index.py`.
