# Data

## Source

The corpus is stored in `data/raw/datasets.json`. It is a local educational corpus assembled from two reproducible sources in this public repository:

- RideFlow NN README and implementation notes;
- `data/processed/demo_moscow_hourly_demand.csv`, the generated Moscow hourly demand dataset used by the RideFlow forecasting demo.

## What Is Indexed

The index contains short documents about:

- project overview;
- demand forecasting;
- trip price estimation;
- geocoding;
- routing;
- weather signals;
- traffic assumptions;
- Streamlit dashboard workflow;
- generated artifacts;
- limitations;
- RAG index design;
- RAG answer policy;
- 1200 hourly Moscow demand observations converted into natural-language text records with city, zone, timestamp, demand value, demand level, weekday, and time bucket.

## Scale

The dataset contains 1212 text records:

- 12 overview records about RideFlow architecture and RAG behavior;
- 1200 demand observation records generated from the local demand CSV.

This satisfies the excellent-grade scale criterion of 1000+ records in `datasets.json`. The corpus remains self-contained and reproducible without a dataset download.

## Generated Files

- `data/processed/documents.jsonl`
- `data/processed/chunks.jsonl`
- `data/index/vectorizer.pkl`
- `data/index/matrix.npz`
- `data/index/chunks.jsonl`

`data/raw/datasets.json` can be regenerated with:

```bash
python scripts/prepare_datasets.py
```

Index files are generated by:

```bash
python scripts/build_index.py
```
